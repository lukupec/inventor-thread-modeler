# Changelog

## 30.1.0 – 2026-11-01

- **Fix: modelling failed with "Failed to create CoilFeature" (E_FAIL) on some parts**, for example an M6 thread in a
  hole of a multi-body part. The coil was created as a cut feature, so Inventor first computed it against every body
  of the part, and its kernel failed where the thread profile touches the threaded face. The coil is now created as a
  separate body and cut out of the thread body only, with a Combine feature. The resulting threads are the same.
- **Thread profile drop-down.** The *Thread Modeler Control* dialog has a *Thread Profile* drop-down with
  **ISO (metric, 60°)**, the default, and **BSW (Whitworth, 55°)**. It replaces the template path field and its
  file browser. Before, the BSW template was the default, so ISO threads were modelled with a Whitworth profile.
- **Configuration** command in the panel's slide-out: assigns the ISO and BSW templates. Templates are checked for
  the required sketch parameters. The settings are stored in `%LOCALAPPDATA%\ThreadModeler\settings.json`.
- **Modelling errors are reported.** A failed modelling now names the step that failed (for example creating the coil
  or a missing template parameter) and writes the exception to the log. Before, every failure showed
  "Failed to create CoilFeature… Try with a bigger Pitch Offset value", and nothing was logged. The pitch-offset
  hint now appears only when the coil itself fails.
- The default pitch offset is shown with the system's decimal separator, so editing it works in locales that use a
  decimal comma.
- New gear icon for *Configuration* (`tools/make_icons.py`).

## 30.0.5 – 2026-11-01

- The *Thread Modeler Control* dialog still showed the old orange coolOrange icon, which was embedded in its form
  resources. It now uses the ThreadModeler bolt icon. The About and update dialogs also show the bolt icon instead
  of the generic .NET window icon.

## 30.0.4 – 2026-11-01

- New neutral icons: a threaded bolt for ThreadModeler, and blue info and help badges. *Check for Updates* gets its
  own green refresh icon. The previous icons were the original coolOrange designs; the About icon was the
  coolOrange "CO" logo.
- Icons are generated by `tools/make_icons.py` (Pillow) and are reproducible.

## 30.0.3 – 2026-11-01

- **Renamed to ThreadModeler.** The coolOrange name and logo are removed from the add-in and installer:
  - ribbon tab and panel *ThreadModeler*;
  - Add-In Manager entry *ThreadModeler*;
  - Windows Apps entry *ThreadModeler for Autodesk Inventor*, publisher *ThreadModeler*;
  - bundle folder `ThreadModeler.bundle`;
  - log and settings in `%LOCALAPPDATA%\ThreadModeler`, policy key `SOFTWARE\ThreadModeler`.
  The MSI upgrades 30.0.x installs in place.
- New About dialog (version, license, project link); Help opens this repository's documentation.
- `LICENSE.txt` and `THIRD-PARTY-NOTICES.txt` (MIT notice of the original coolOrange project, Autodesk ADN notice)
  are installed with the add-in.

## 30.0.2 – 2026-11-01

- **Fix: add-in stayed "Automatic / Unloaded" in Inventor 2026.4.** The add-in depended on log4net 3.5. When
  Inventor or another add-in (for example Vault) had already loaded a different log4net version, .NET refused
  to load ours, and the add-in failed while Inventor created it, before any error handling could run.
  log4net is replaced by a small built-in logger, so the add-in has no third-party dependencies.
- The log moves to `%LOCALAPPDATA%\coolOrange\ThreadModeler\threadModeler.log`, which is writable for every user.
  It also records how the add-in was loaded (runtime, load context, Inventor interop) and any assembly that
  could not be resolved.
- Type-load failures inside `Activate` are now caught and reported too.
- `.addin` manifest back to the original UTF-16 format without comments; `UseInventorAssemblyContext`
  removed (its value 1 is Inventor's default).

## 30.0.1 – 2026-11-01

- **Installer**: per-machine MSI (`ThreadModeler-<version>.msi`) from GitHub Releases. Double-click to install;
  it replaces older ThreadModeler installs. Silent install supported (`DISABLEUPDATECHECK=1` for IT-managed updates).
- **Automatic update check**: once a day Inventor checks GitHub for a newer release and offers to download it.
  The MSI is verified with SHA-256 and installed after Inventor is closed. *Check for Updates* button in the
  panel's slide-out.
- **Fix: add-in could stay "Automatic / Unloaded"**: the Inventor interop is no longer embedded, and the
  add-in loads into Inventor's shared assembly context.
- Load errors are shown and written to `%TEMP%\ThreadModeler-load-error.txt`, instead of failing silently.
- Fix: tapered-thread radius computation passed the face geometry instead of the face (upstream bug).
- Single version source (`Directory.Build.props`); release workflow publishes on `vX.Y.Z` tags.
- Unit tests for the update logic.

## 30.0.0 – 2026-11-01

Port to .NET 10 for Autodesk Inventor 2026 (Update 2026.4+) and Inventor 2027.

- Target `net10.0-windows` (SDK-style project, Visual Studio 2026 / .NET 10 SDK).
- Distributed as an ApplicationPlugins bundle (`cODTthreadModeler.bundle`) instead of a WiX MSI.
- `.addin` manifest: supports Inventor 2026+ and loads in an isolated assembly context on Inventor 2027.
- log4net 3.5.0.
- Removed registry-free COM manifest and RegAsm/registry install helpers.
- Fixed opening the Help / coolOrange links on .NET 10.
- Resources load without BinaryFormatter.
- Build scripts (`build.ps1`, `build.sh`) and GitHub Actions build.

See [docs/MIGRATION.md](docs/MIGRATION.md) for details.
